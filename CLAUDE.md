# slapmod

A Claude Code mod (function hooks plugin) plus a native Swift helper that reads the MacBook accelerometer. Open source (MIT): never commit signing identities, team IDs, notary profile names, local paths or anything from the proprietary SlapMac repo.

## Layout
- `hooks/register.tsx`: the hooks module. Functions that take `$` must be top-level declarations (the engine's loader refuses closures inside `register`); per-session state lives in the module's `settings`/`live` objects, drawn state in `$.state` atoms declared in `types/index.d.ts`.
- `hooks/format.ts`: pure helpers (line protocol, meter, the note Claude reads), tested directly.
- `helper/`: Swift package. `SlapsenseCore` is the pure detector, `slapsense` the IOKit executable printing JSON lines.
- `native/slapsense`: the signed, notarized arm64 binary the mod runs. Rebuild it with `Scripts/build-helper.sh` after any helper change; signing settings come from `.env.local` (gitignored).
- `sounds/`: generated by `Scripts/make-sounds.py`.

## Checks
- `swift test --package-path helper`
- `claude plugin validate .` and `claude plugin test .`
- `pnpm typecheck` (needs `.claude-plugin/types/`, laid when Claude Code loads the mod)

## Conventions
- Named constants at the top of each file, no magic numbers.
- UI copy is short, casual, no em dashes.
- Bump `version` in `plugin.json`, `package.json` and the helper's `main.swift` together, and add a `changelog.md` entry in the same commit.
