# slapmod

A Claude Code mod (function hooks plugin) plus a native Swift helper that reads the MacBook accelerometer. Open source (MIT): never commit signing identities, team IDs, notary profile names, local paths or anything from the proprietary SlapMac repo.

## Layout
- `hooks/register.tsx`: hook wiring only. Matchers use literals declared in this file, so the loader can read them.
- `hooks/state.ts`: the only file that touches `$.state`. The loader accepts state sources declared in the file that uses them, so other files call its `read…`/`set…` functions. `settings` comes from this load's options, and `live` holds per-load state. Both start over on a reload, and every settings change causes one.
- `hooks/actions.ts`: what a slap does (gestures, stop, command, prompt), settings writes through `$.config.set` (queued in `$.store`, since each write reloads the module), and the dial.
- `hooks/helper.ts`: the helper's lifecycle, and `startSession`.
- `hooks/pane.tsx`: the meter view and the settings page.
- `hooks/format.ts`: pure helpers (the line protocol, settings parsing, `/slap` arguments, the gesture reducer, the meter, the note Claude reads), tested directly.
- Functions that take `$` must be top-level declarations, in their own file or imported from the plugin's own files.
- `helper/`: Swift package. `SlapsenseCore` is the pure detector, and `slapsense` is the IOKit executable that prints JSON lines (`--threshold <g>`).
- `native/slapsense`: the signed, notarized arm64 binary the mod runs. Rebuild it with `Scripts/build-helper.sh` after any helper change; the signing settings come from `.env.local` (gitignored).
- `sounds/`: generated by `Scripts/make-sounds.py`.
- The mod's own `prompt.submit` hook doesn't see its own `$.prompt.submit`, so the slap note goes into that prompt's text.

## Checks
- `swift test --package-path helper`
- `claude plugin validate .` and `claude plugin test .`
- `pnpm typecheck` (needs `.claude-plugin/types/`, laid when Claude Code loads the mod)

## Conventions
- Named constants at the top of each file, no magic numbers.
- UI copy is short, casual, no em dashes.
- Bump `version` in `plugin.json`, `package.json` and the helper's `main.swift` together, and add a `changelog.md` entry in the same commit.
